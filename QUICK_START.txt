                  vib3 - 三分钟快速启动指南
═══════════════════════════════════════════════════════════════

【核心功能】
采集中国知识产权局（CNIPA）的专利数据：
- 14 个基础字段（名称、申请人、类型等）
- 3 个发文信息字段（仅针对驳回案件）
- 共 490 条已采集记录

═══════════════════════════════════════════════════════════════
【完整启动步骤】
═══════════════════════════════════════════════════════════════

1️⃣  准备依赖（仅首次需要）
─────────────────────────
pip install undetected-chromedriver selenium pyautogui \
            mitmproxy pandas openpyxl

2️⃣  终端 1：启动 MITM 代理
──────────────────────────
cd /home/cxm/Desktop/vib3
python start_mitm_proxy.py

↳ 应该看到：
  [+] 启动 mitmproxy...
  [*] 监听地址: 127.0.0.1:8080

3️⃣  终端 2：启动采集程序
──────────────────────────
cd /home/cxm/Desktop/vib3
USE_MITM_PROXY=true python main_automation.py

↳ 程序会自动读取 data/search_list.txt 中的申请号列表，
  逐个采集专利数据，并保存到 detection_log.json

【常见问题】
═══════════════════════════════════════════════════════════════

Q: 程序卡在某个申请号怎么办？
A: 按 Ctrl+C 中断，重新运行程序。程序会自动跳过已采集的
   申请号，继续采集新的数据（支持断点续传）。

Q: MITM 代理启动失败？
A: 检查是否已安装 mitmproxy：
   pip install mitmproxy

Q: 浏览器连接不到代理？
A: 检查 8080 端口是否被占用：
   lsof -i :8080

   如被占用，关闭占用的进程后重试。

Q: 需要采集更多申请号？
A: 编辑 data/search_list.txt，添加新的申请号，
   然后重新运行程序即可。
