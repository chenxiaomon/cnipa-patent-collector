# CNIPA 公开搜索批量采集指南

本指南说明如何使用新的公开搜索模块来批量采集 1000+ 条专利数据。

## 📋 快速概览

**采集模式**: 按申请人/技术分类进行公开搜索，**手动翻页** + MITM 自动采集

**核心优势**：
- ✅ 批量采集 1000+ 条数据（相比单个申请号查询）
- ✅ **极简易用**：只需浏览器手动操作，系统自动采集
- ✅ **高度灵活**：可随时暂停、监控进度、调整速度
- ✅ **无反爬虫风险**：人工操作比自动脚本更"自然"
- ✅ **完整的数据导出**：Excel + JSON 格式

**涉及文件**：
- `start_mitm_public_search.py` - 启动 MITM 代理（自动采集引擎）
- `mitm_addon_public_search.py` - MITM 拦截插件
- `export_public_search.py` - 数据导出脚本
- `auto_paginate.py` - *可选* 自动翻页脚本（高级用法）

#### **步骤 2：在浏览器中手动采集**

1. **打开浏览器**（Chrome / Firefox / Edge）

2. **配置浏览器代理** → 指向 `127.0.0.1:8080`
   - 这样浏览器的所有流量都会通过 MITM 代理
   - 代理会自动拦截并保存 API 响应

3. **访问 CNIPA 公开搜索页面**
   ```
   https://cponline.cnipa.gov.cn/publicSearch
   ```

4. **输入查询条件**
   - 申请人：输入公司名称（例如 "阿里巴巴"）
   - 技术分类：可选
   - 其他条件：可选

5. **点击"查询"按钮**
   - 等待搜索结果加载
   - MITM 代理自动拦截第 1 页的数据

6. **手动点击"下一页"按钮**
   - 点击一下 → MITM 自动采集第 2 页
   - 再点击 → MITM 自动采集第 3 页
   - **重复点击直到最后一页**
   - 💡 **按你的节奏点击**，可快可慢，完全由你控制

7. **监控采集进度**（看终端 1）

## 🔧 手动采集 vs 自动翻页

| 对比项 | 手动采集 | 自动翻页脚本 |
|--------|--------|------------|
| 使用难度 | ⭐ 极简 | ⭐⭐⭐ 需要脚本 |
| 灵活性 | ⭐⭐⭐ 很高 | ⭐⭐ 受延迟限制 |
| 采集速度 | ⭐⭐⭐ 由你控制 | ⭐⭐ 固定延迟 |
| 人工操作 | ⭐⭐ 需要点击翻页 | ⭐ 点一下后自动 |
| 适用场景 | 小/中规模（<50页） | 大规模（50+页） |

**推荐**：
- **小规模采集**（<500 条）：用手动采集
- **大规模采集**（500+条）：用自动翻页脚本
- **边采集边检查**：用手动采集，监控数据质量

## 💡 手动采集的优势

1. **无需等待固定延迟**
   - 页面加载慢就多等几秒
   - 页面加载快就立即点击
   - 完全由你控制

2. **随时暂停**
   - 可以在任何时刻停下来
   - 数据已保存在 `data/raw_responses/`
   - 稍后继续采集其他申请人

3. **实时监控**
   - 在终端 1 实时看到采集进度
   - 如果某一页出错，立即发现
   - 可以根据数据质量调整查询条件

4. **无反爬虫风险**
   - 人工操作看起来很"自然"
   - 比自动脚本更难被反爬虫系统检测

5. **简单可靠**
   - 不需要理解复杂的脚本逻辑
   - 问题更容易排查

## ⚠️ 常见问题

### Q1: 浏览器无法连接到代理

**问题**：显示 "无法访问此网站" 或超时

**解决**：
1. 检查 MITM 代理是否正常运行（终端 1 有输出）
2. 检查代理配置是否正确（127.0.0.1:8080）
3. 重启浏览器或清除浏览器缓存

### Q2: MITM 代理报错 "Port already in use"

**解决**：
```bash
# 查看占用端口的进程
lsof -i :8080

# 关闭占用的进程（获取 PID 后）
kill -9 <PID>
```

### Q3: 采集了多页但导出的数据很少

**检查**：
1. 查看 `data/raw_responses/` 目录，数一下有多少个 JSON 文件
2. 查看某个 JSON 文件内容，确认有记录数据
3. 运行 `python export_public_search.py` 看是否有报错

### Q4: 某些 Excel 列为空

**这是正常的**：
- CNIPA 数据库中可能不存在某些字段
- API 可能不会返回所有字段
- 这不影响导出，可以在 Excel 中过滤

### Q5: 需要采集多个申请人的数据

**方案**：
1. 采集申请人 A（手动翻页）
   - 终端 1 会生成 `undomestic_0001_*.json`, `undomestic_0002_*.json`, ...

2. 采集申请人 B（手动翻页）
   - 继续使用同一个 MITM 代理
   - 新页面会生成 `undomestic_0051_*.json`, `undomestic_0052_*.json`, ...

3. 导出所有数据（自动去重）
   ```bash
   python export_public_search.py
   ```
   - 会自动合并所有 JSON 文件
   - 按申请号去重

## 🎬 高级用法：自动翻页脚本（可选）

如果你需要采集 **50+ 页**的数据，可以使用自动翻页脚本，这样可以设置后离开：

### 使用自动翻页脚本

#### 步骤 1：启动 MITM 代理（终端 1）
```bash
python start_mitm_public_search.py
```

#### 步骤 2：启动自动翻页脚本（终端 2）
```bash
python auto_paginate.py --delay 1.5 --max-pages 50
```

#### 步骤 3：浏览器中手动输入查询条件
1. 输入申请人（在脚本打开的浏览器中）
2. 点击"查询"按钮
3. 回到终端 2，按 Enter 键

#### 步骤 4：脚本自动翻页
- 脚本会自动点击"下一页"按钮
- 每页间隔 1.5 秒（可用 `--delay` 调整）
- 最多翻 50 页（可用 `--max-pages` 调整）

### 参数说明

```bash
python auto_paginate.py [OPTIONS]
```

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--delay` | 1.5 秒 | 翻页延迟（秒）。增加此值避免反爬虫 |
| `--max-pages` | 50 | 最多翻多少页 |
| `--test` | N/A | 测试模式（例如 `--test 5` 只翻 5 页） |

### 示例

```bash
# 快速采集：每 1 秒翻一页，最多翻 30 页（约 30 秒）
python auto_paginate.py --delay 1 --max-pages 30

# 安全采集：每 2 秒翻一页，最多翻 100 页（约 3 分钟）
python auto_paginate.py --delay 2 --max-pages 100

# 测试：只翻 3 页，验证系统工作正常
python auto_paginate.py --test 3
```
