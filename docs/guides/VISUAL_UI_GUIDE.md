# CNIPA 可视化控制台使用指南

## 启动

在项目根目录运行：

```bash
python web_dashboard.py
```

默认地址：

```text
http://127.0.0.1:8765
```

如果端口被占用：

```bash
python web_dashboard.py --port 8766
```

## 能做什么

控制台把原来的常用命令集中到一个本地网页里：

| 区域 | 功能 |
|------|------|
| 采集概览 | 查看总记录数、成功率、驳回目标、发文补采、动态清单数量 |
| 日常采集 | 启动主 MITM 代理、测试采集、继续全量采集、按清单更新 |
| 状态检查策略 | 生成动态更新清单、查看策略状态、单号判断、快照/差异/报告 |
| 公开查询 | 启动 publicSearch 代理、打开浏览器、自动翻页、导出结果 |
| 任务日志 | 查看每个后台任务的实时输出，也可以停止仍在运行的任务 |
| 申请号列表 | 直接编辑 `data/search_list.txt` |
| 坐标配置 | 直接编辑 `data/config.json` |
| 最近记录 | 查看最新写入的采集记录 |

## 推荐流程

### 测试采集

1. 打开控制台。
2. 点击 `启动主代理`。
3. 确认顶部显示 `主代理在线`。
4. 在 `测试条数` 输入 5。
5. 点击 `强制测试`。
6. 在 `任务日志` 里观察输出。

说明：`强制测试` 会重新采集 `data/search_list.txt` 中前 N 个申请号，即使这些申请号之前已经采过。这样适合验证浏览器、代理、坐标和 MITM 链路是否正常。`继续全量采集` 则保留断点续传逻辑，只处理尚未采集的申请号。

### 日常状态检查

1. 点击 `生成清单`，生成 `data/update_list_dynamic.txt`。
2. 点击 `保存快照`，记录采集前状态。
3. 点击 `启动主代理`。
4. 在 `更新清单` 选择 `动态清单`。
5. 点击 `按清单更新`。
6. 采集结束后点击 `状态变化` 或 `详细报告`。

## 注意事项

- 控制台只监听本机地址 `127.0.0.1`，适合在采集机器上本地使用。
- 页面按钮调用的是白名单脚本，不执行任意 shell 命令。
- 启动采集、补采、浏览器等任务时，仍然需要遵守原系统要求：不要移动鼠标、不要关闭浏览器窗口。
- 如果网页显示主代理未连接，先点击 `启动主代理`，或确认端口 `8082` 没有被其他进程占用。
- 如果页面提示输入框和查询按钮坐标相同，先在 `坐标配置` 区域点击 `重录坐标`，再运行 `强制测试`，按任务日志提示把鼠标移动到对应位置等待倒计时捕获。
