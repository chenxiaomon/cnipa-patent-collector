# 采集与维护流程补强

用户授权继续处理上一轮审查列出的六项问题。开发与验证使用 Mac 隔离副本及合成数据，公司 Windows 实机不在本地。

## 范围与归属

1. 看门狗固定本次批次 ID，自动重启仍续跑该批未成功目标，以批次状态判定完成；主采集目标选择由同一模块负责。
2. 发文采集使用独立采集时间，保持基础案件状态时间不变；旧记录时间不推测、不批量回写。
3. 更新与回滚共同持有维护锁，排斥桌面采集和看门狗全生命周期，包含重试等待间隙。
4. 筛选 Excel 仅生成成功才返回下载，失败明确报错，所有路径清理临时文件。
5. 任务列表保留全部运行中任务，仅限制已结束历史并回收旧日志对象。
6. 保存、采集加载和环境诊断共用零依赖坐标规则；允许空配置补录，拒绝非法类型和整对占位值。

## 约束

- 每项改动留在各自负责模块；Dashboard 只做接口边界校验和任务冲突提示。
- 不在真实工作区导入项目模块或执行数据库测试；专利库只通过 PatentsDB 读写。
- 保持现有日期版本和未发布 r1，发布清单最后生成；本机运行锁不入 Git。
- Windows CI 和公司现场验收分别核对，不以 Mac 测试代替。
