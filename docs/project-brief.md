# 项目简述 - CNIPA Patent Collector

## 项目目标

自动化从中国知识产权局（CNIPA）官方网站采集专利数据，包括基础信息和法律状态变化，支持**条件采集**（仅对驳回等复审状态的案件采集发文信息）。

## 核心价值

- **完整性**: 采集申请号 + 13 个基础字段 + 3 个发文字段（条件采集）
- **可靠性**: 支持断点续传，浏览器启动自动重试，采集失败支持手动重试和补采，中断恢复
- **规模**: 支持 500+ 条记录，内存和存储占用可控
- **可维护性**: 模块化设计，便于扩展和问题排查

## 项目范围

### ✅ 包含

| 类别 | 范围 |
|-----|------|
| **采集方式** | MITM 代理拦截 API + PyAutoGUI 物理操作 |
| **采集触发** | 基础字段全量采集；发文字段条件采集（anjianywzt='驳回等复审请求'） |
| **错误处理** | 网络超时、部分数据缺失、采集失败重试 |
| **输出格式** | JSON（日志）+ Excel（最终报表） |
| **状态管理** | 已采集申请号去重，支持从中断点续传 |

### ❌ 非目标

| 项目 | 原因 |
|-----|------|
| **纯 DOM 自动化** | CNIPA 网站复杂，易被反爬；MITM 更稳定 |
| **数据库存储** | 当前规模用文件系统，后续可升级 |
| **实时监控** | 单次采集设计，不涉及轮询 |
| **分布式采集** | 单机顺序执行，防止大规模 IP 被封 |
